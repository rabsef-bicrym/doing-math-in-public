# Canonical Lean source snapshot

This directory preserves the integrated `rabsef-talwet` formalization from branch
`octagon-envelope-2026-07-24`, exported on 2026-08-01. It is kept as an exact
source snapshot, including modules that are incomplete, superseded, or not part
of a single currently-green dependency graph.

Run Lean from this directory. The pinned toolchain is Lean 4.30.0 with Mathlib
4.30.0. Consult the project-level `STATUS.md` before treating any module as an
end-to-end theorem.

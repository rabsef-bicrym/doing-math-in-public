# Integrated private proof branch provenance

The canonical Lean tree in this migration branch is reconstructed from the dedicated proof repository `rabsef-bicrym/rabsef-talwet`, chiefly branch `octagon-envelope-2026-07-24` and draft PR #2, together with retained green source bundles produced during that development.

The migration deliberately separates these integrated sources from the dependency-isolated `lean/standalone` tree imported from temporary public CI. Duplicate module names and incompatible normalizations are preserved until a reviewed consolidation chooses one canonical definition.

No claim that the unrestricted conjecture is complete follows from this source migration.
